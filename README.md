# 中華麥塊 ChunghwaMC

中華麥塊(英文：ChunghwaMC，縮寫 chmc)，簡稱華麥、中麥，是 2012 年開始營運的台灣 Minecraft 伺服器組織。另提供代開伺服器、各式網站與 DNS 等服務。官方網站為 chunghwamc.com。

ChunghwaMC (中華麥塊, chmc) is a Taiwanese Minecraft server organization operating since 2012. It also provides server hosting, various websites, and DNS services. Website: chunghwamc.com.
